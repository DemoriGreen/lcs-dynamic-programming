# Longest Common Subsequence – Dynamic Programming

This project compares three approaches for solving the Longest Common Subsequence (LCS) problem used in DNA sequence analysis.

Algorithms implemented:

1. Naive Recursive
2. Memoization (Top-Down Dynamic Programming)
3. Tabulation (Bottom-Up Dynamic Programming)

The goal is to demonstrate how dynamic programming improves performance compared to pure recursion.

Example:
Sequence 1: AGGTAB
Sequence 2: GXTXAYB

LCS = GTAB
Length = 4
